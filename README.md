# Mon portfolio

![Status](https://img.shields.io/badge/Status-Active%20Development-orange) ![Version](https://img.shields.io/github/v/release/bou-ciel1/Mon-Portfolio?label=Version&color=blue)

## Description courte
Mon portfolio personnel présentant mon parcours et mes projets, conçu pour centraliser mes compétences techniques et mes réseaux sociaux.

## Fonctionnalités
- Présentation de mes formations, expériences professionnelles, certifications et projets informatiques
- Renvoi vers mes réseaux sociaux avec des boutons
- Mode Clair/Sombre et Traduction Français/Anglais
- Renvoi vers mes dépôts GitHub en cliquant sur les projets
